# Вступ
Git - найбільш використовувана система контролю версій, на ній тримається більшість проєктів з відкритим кодом.
Git належить до SFC (Software Freedom Conservancy) як повністю відкритий проєкт з відкритою ліцензією.

## Встановлення
Перед тим як користуватися Git'ом вам потрібно його встановити. Різні системи мають різні менеджери пакунків.

### Windows
Ручне встановлення за допомогою інсталятора з git-scm.com. [Посилання](https://git-scm.com/install/windows). </br>
Встановлення за допомогою **WinGet** ->```winget install --id Git.Git```.

### macOS
Використовуючи **Homebrew** -> ```brew install git``` </br>
Використовуючи **xCode** -> ```xcode-select --install```

### Linux
**Debian/Ubuntu** -> ```apt install git```

**Fedora** -> ```dnf install git```

**ArchLinux** -> ```pacman -S git```
